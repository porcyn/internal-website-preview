          1
          
การเลือกและสลับบัญชีบอท (Bot Selector)

        

        

          ระบบมีปุ่มสลับบอทอยู่ที่แถบมุมบนขวาของหน้าจอเสมอ เพื่อความปลอดภัยในการทำงาน:
        

        

          

            

              บอทหลัก (@traffyfondue)
            

            

              เป็นบัญชีทางการ (Production) ที่ประชาชนทั่วประเทศใช้งานจริง หากแก้ไขจะมีผลทันที ควรตรวจสอบให้รอบคอบก่อนบันทึก
            

          

          

            

              บอททดสอบ (@583mbpbd)
            

            

              เป็นบัญชี Prototype สำหรับฝ่ายพัฒนาและแอดมินทดลองเพิ่มเมนู หรือฟังก์ชันใหม่ โดยไม่รบกวนผู้ใช้งานจริง
            

          

        

      


      
      

        

          2
          
การจัดการ LINE Rich Menu (เมนูกดบนมือถือ)

        

        

          Rich Menu คือแถบเมนูลัดที่ตรึงอยู่ด้านล่างจอแชท LINE มี 4 ขั้นตอนในการสร้างและแก้ไข:
        

        

          

            ขั้นตอนที่ 1:
            เลือกเทมเพลตปุ่ม: กำหนดจำนวนช่อง เช่น แบบ 6 ช่องยอดนิยม (แจ้งเรื่อง, ติดตามสถานะ, เบอร์ฉุกเฉิน ฯลฯ) หรือแบบ 4 ช่อง
          

          

            ขั้นตอนที่ 2:
            ใส่รูปภาพและสี: อัปโหลดภาพแบนเนอร์ขนาดมาตรฐาน 2500×1686 หรือใช้เครื่องมือจัดวางไอคอนและสีปุ่มของระบบ
          

          

            ขั้นตอนที่ 3:
            กำหนดคำสั่งกดปุ่ม (Actions): เลือกว่ากดช่องไหนให้เปิดลิงก์ (URL เช่น หน้าแจ้งเรื่อง Traffy) หรือให้พิมพ์ข้อความ (Text คำสั่ง) ส่งให้บอท
          

          

            ขั้นตอนที่ 4:
            บันทึก & เผยแพร่: กดปุ่ม "ตั้งเป็นเมนูหลัก (Default)" เพื่อให้แสดงผลในแอป LINE ของประชาชนทันที
          

        

      


      
      

        

          3
          
การตั้งค่าผังคำตอบ & ข้อความ (Dialogue Flow)

        

        

          ผังคำตอบใช้ควบคุมว่าเมื่อผู้ใช้ส่งข้อความอะไรมา บอทจะตอบกลับอย่างไร:
        

        
    
          
  • State (กล่องสถานะ): แทนเงื่อนไข เช่น เมื่อผู้ใช้พิมพ์ว่า "แจ้งเรื่อง" หรือกดปุ่มเมนูหลัก
    • 
          
  • Action (คำสั่งตอบกลับ): สิ่งที่บอทจะส่งตอบกลับ เช่น ข้อความตัวอักษร (Text), หรือการ์ดปุ่มกด (Flex Message)
    • 
          
  • การตรวจคำสั่งชนกัน (Conflict Detection): หากมี State ซ้ำกันระบบจะเตือนด้วยสีส้มทันที เพื่อป้องกันไม่ให้บอทส่งคำตอบผิด
    • 
        

      


      
      

        

          4
          
การทดสอบในห้องจำลองแชท (LINE Simulator)

        

        

          เป็นเครื่องมือทดลองคุยกับบอทเสมือนจริงบนหน้าจอมือถือก่อนนำไปเผยแพร่จริง:
        

        

          
• ทดสอบพิมพ์คุย: พิมพ์ข้อความในช่องแชทด้านล่างจอมือถือ แล้วกดส่งเพื่อดูการตอบกลับ

          
• ทดสอบปุ่ม Rich Menu: คลิกปุ่มบนเมนูด้านล่างจอโทรศัพท์ เพื่อตรวจดูว่าเปิดลิงก์หรือส่งข้อความถูกต้องหรือไม่

          
• ทดสอบส่งพิกัด GPS: กดปุ่มหมุด เพื่อจำลองส่งพิกัดตำแหน่ง เช่น เสาชิงช้า หรือสยามสแควร์

          
• แถบ Context ด้านขวา: แสดงตัวแปรของระบบและขั้นตอนที่บอทรันในขณะนั้นแบบเรียลไทม์

        

      


      
      

        

          5
          
เครื่องมือเทคนิคขั้นสูง (สำหรับฝ่ายพัฒนา)

        

        

          อยู่ในเมนู "เครื่องมือเทคนิค (Dev)" ทางด้านขวา ประกอบด้วย:
        

        

          

            Action Pipeline: ตรวจสอบลำดับการรันคำสั่งเชิงลึกและ JSON Payload
          

          

            ตารางฐานข้อมูล (DB): ตรวจสอบตาราง PostgreSQL state และ action-list
          

          

            ตรวจสถานะ (Diagnostics): ตรวจเช็ค State ที่ซ้ำซ้อนและปุ่มกด Rebuild Cache
          

          

            ตั้งค่า API: จัดการ Webhook URL และ Channel Access Token
          

        

      


    


    

      สามารถกดปุ่ม "คู่มือการใช้งาน" ที่มุมบนขวาเพื่อเปิดหน้านี้ได้ทุกเวลา
